Armamentos e Conflitos – Banco de Dados em PostgreSQL

Este projeto foi desenvolvido como parte do meu processo de aprendizado e construção de portfólio na área de dados e banco de dados. O foco principal foi praticar a modelagem de um banco de dados relacional e a criação de consultas SQL utilizando PostgreSQL por meio do pgAdmin 4.

A ideia do projeto surgiu da necessidade de trabalhar com dados reais, porém públicos, aplicando conceitos fundamentais de banco de dados de forma prática e compreensível para um nível iniciante.

Objetivo do Projeto

O objetivo deste projeto é consolidar conhecimentos em SQL, principalmente na criação de tabelas, definição de chaves primárias e estrangeiras, relacionamento entre dados e execução de consultas básicas para análise. Além disso, o projeto foi pensado para servir como base para evoluções futuras, como a integração com aplicações externas e o desenvolvimento de um chatbox especializado em dados geopolíticos.

Uso de Inteligência Artificial

Durante o desenvolvimento deste projeto, ferramentas de Inteligência Artificial foram utilizadas como assistentes de apoio ao aprendizado. A IA auxiliou na organização das ideias, na compreensão dos conceitos de banco de dados, na estruturação das tabelas e no entendimento das consultas SQL.

O uso da IA teve caráter educacional e orientativo. Todas as decisões, execuções e validações do código foram feitas de forma consciente, com o objetivo de compreender o funcionamento do banco de dados e não apenas reproduzir comandos.

Sobre os Dados Utilizados

Os dados armazenados neste banco são reais e de domínio público. As informações foram coletadas manualmente a partir de fontes abertas, como a Wikipédia, e utilizadas exclusivamente para fins educacionais.

O banco contém informações descritivas, como nome do armamento, categoria, país de origem e alcance aproximado. Não há dados sensíveis, operacionais ou instrutivos, respeitando limites éticos e acadêmicos.

Estrutura do Banco de Dados

O banco de dados foi modelado de forma simples e clara, sendo composto por tabelas que representam países, categorias de armamentos e os próprios armamentos. As tabelas estão relacionadas entre si por meio de chaves estrangeiras, permitindo a realização de consultas que conectam essas informações de maneira coerente.

Essa estrutura facilita tanto o aprendizado quanto a futura expansão do projeto.

Consultas SQL

O projeto inclui consultas SQL voltadas para iniciantes, com o objetivo de facilitar o entendimento do que está sendo executado. As consultas permitem visualizar os dados cadastrados, relacionar armas com seus países e categorias, aplicar filtros simples, ordenar resultados e realizar contagens e médias básicas.

Todas as consultas foram pensadas para serem legíveis e didáticas, priorizando a compreensão ao invés da complexidade.

Tecnologias Utilizadas

O projeto foi desenvolvido utilizando PostgreSQL como sistema de gerenciamento de banco de dados, pgAdmin 4 como ferramenta de administração e a linguagem SQL para criação e consulta dos dados.

Evoluções Futuras

Este projeto foi planejado para continuar evoluindo. Entre as possibilidades futuras estão a expansão do banco com novos dados, a criação de consultas mais analíticas, a integração com Python e o desenvolvimento de um chatbox que utilize este banco como fonte de dados para responder perguntas relacionadas ao tema.

Considerações Finais

Este projeto representa uma etapa importante do meu aprendizado na área de dados. Mais do que um resultado final, ele reflete o processo de estudo, prática e entendimento dos conceitos fundamentais de banco de dados relacionais e SQL.
